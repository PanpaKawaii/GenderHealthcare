# Gender Healthcare Assignment

This project is part of the SDN302 course assignment. It focuses on building a healthcare-related application.

## Features

- Booking 
- View hostory of booking

## Getting Started
1. Install dependencies:
    ```bash
    npm install
    ```
2. Start the application:
    ```bash
    npm start
    ```
 ## Data Files

The `data` folder contains sample JSON files that you can use to import initial data into MongoDB. After download the project, you will find files such as:

- `gender-healthcare.customers.json`
- `healthcare.account.json`
- `healthcare.consultationbooking.json`
- `healthcare.consultationschedule.json`
- `healthcare.counselor.json`
